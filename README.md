# 🏥 Hospital Management System

A full-featured Hospital Management System built with **Python Flask, MySQL, and Bootstrap 5** to streamline hospital operations, patient management, appointments, billing, and healthcare workflows.

## ✨ Features

### 👥 Role-Based Access
- **Admin:** Manage users, doctors, patients, appointments, and system analytics.
- **Receptionist:** Manage patient check-ins, appointments, and billing.
- **Doctor:** View assigned patients, manage appointments, and access patient records.
- **Patient:** Register, book appointments, and view health information.

### 🩺 Core Functionality
- Secure user authentication and role-based access control.
- Patient registration and profile management.
- Appointment booking and confirmation workflow.
- Intelligent doctor recommendations based on disease categories.
- Health risk assessment based on patient information.
- Patient health records management.
- Bill generation and management.
- Notifications and dashboard analytics.

## 🚀 Getting Started

### Prerequisites

Install the following before running the application:

- Python 3.8 or later
- MySQL Server
- Git

### 1. Clone the Repository

```bash
git clone <your-repository-url>
cd hospital_system
```

Replace `<your-repository-url>` with your GitHub repository URL.

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Set Up the Database

Make sure your MySQL server is running, then execute:

```bash
mysql -u root -p < database_schema.sql
```

This initializes the `hospital_db` database and creates the required tables and predefined records, as configured in the SQL file.

### 4. Configure the Database

Open `config.py` and update the database credentials:

```python
DB_HOST = 'localhost'
DB_USER = 'root'
DB_PASSWORD = 'your_password'
DB_NAME = 'hospital_db'
```

Replace `your_password` with your MySQL password.

**Security note:** Never commit real database passwords or secret keys to a public repository.

### 5. Run the Application

```bash
python app.py
```

Open your browser and visit:

**http://localhost:5000**

## 🔄 How It Works

### Patient Workflow
1. Register and log in.
2. Select a doctor and book an appointment.
3. Wait for appointment confirmation.
4. Attend the appointment.
5. View health information and billing details.

### Receptionist Workflow
1. Log in to the receptionist dashboard.
2. Review pending appointments.
3. Confirm appointments.
4. Manage billing and patient appointments.

### Doctor Workflow
1. Log in to the doctor dashboard.
2. Review assigned patients and upcoming appointments.
3. Access relevant patient records.
4. Mark appointments as completed.
5. Review billing information generated by the system.

### Admin Workflow
1. Log in to the admin dashboard.
2. Monitor system statistics.
3. Manage doctors, patients, and appointments.
4. Review appointment history and operational analytics.

## 🔒 Security

The project documentation identifies the following security features:

- Password hashing.
- Session-based authentication.
- Role-based access control.
- SQL injection prevention.
- CSRF protection.

**Note:** Verify these protections in the actual implementation before describing the application as secure. In particular, use a password-hashing algorithm designed for passwords, such as Werkzeug's password-hashing utilities, rather than plain SHA-256.

## 🐛 Troubleshooting

### MySQL Connection Error

- Ensure MySQL Server is running.
- Verify the credentials in `config.py`.
- Confirm that `database_schema.sql` was executed successfully.

### Port 5000 Already in Use

Change the port in the application entry point:

```python
app.run(debug=True, host='localhost', port=5001)
```

Then open `http://localhost:5001`.

### Flask Module Not Found

Install the project dependencies:

```bash
pip install -r requirements.txt
```

### School or Database Records Missing

Check the database initialization script and confirm that the required tables and records exist.
